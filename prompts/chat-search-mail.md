## Task: search related emails

Find the email threads about the attached task(s). Start from the counterpart address if there is one,
then the names and key words in the title; try two or three searches. Read the latest message of the
most relevant threads. Reply with the state of each thread in one line (who wrote last, when, what is
pending). Propose `link_thread` for every thread that belongs to the task, and any change the mail
proves (a date, `waiting_on`, done). If nothing relevant turns up, say so.
